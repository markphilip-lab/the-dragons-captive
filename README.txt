# The Dragon's Captive - Finished Game Base

This version includes:
- Main menu
- WASD movement
- Space / left-click attack
- Attack animation
- 3-heart health
- Wall collision
- Tile-style dungeon
- Floors 1-5
- 5-7 enemies per floor
- Bat enemies
- Skeleton enemies
- Dragon boss
- Locked/open exit door
- Kill-all-enemies progression
- Game Over
- Retry
- Main Menu
- Princess rescue
- Victory screen

## Custom assets

Put your own PNG files here:

assets/characters/warrior.png
assets/characters/princess.png
assets/enemies/bat.png
assets/enemies/skeleton.png
assets/enemies/dragon.png

The game has simple drawn fallbacks, so it still runs if these images are missing.

Open index.html with a local server (such as VS Code Live Server) for best results.
